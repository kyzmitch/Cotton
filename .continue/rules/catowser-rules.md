# Project Architecture

This is a Swift application with:

- It provides SwiftUI and UIKit modes for ios application at `catowseriOS`
- Base modules are at `catowseriOS/Base`
- Domain modules are at `catowseriOS/Domain`
- Presentation modules are at `catowseriOS/Presentation`
- It provides Jetpack compose for Android application at `catowserAndroid`

## Coding Standards

- Use Swift language for all new files
- Follow the existing naming conventions
- Write unit tests for all new features
